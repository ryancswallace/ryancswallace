## Selected work

- **[Jobman](https://github.com/ryancswallace/Jobman)** — A job execution
  platform with daemonless local operation and an optional shared control plane.
  The platform includes
  [Jobman Control](https://github.com/ryancswallace/Jobman-Control) for
  PostgreSQL-backed coordination and
  [Jobman Diagnose](https://github.com/ryancswallace/Jobman-Diagnose) for
  deterministic and AI-assisted failure analysis.
  [Documentation](https://jobman.tech/) ·
  [Technical articles](https://ryancswallace.dev/tags/jobman/)

- **[benchmatrix](https://github.com/ryancswallace/benchmatrix)** — A Python
  toolkit for reproducible benchmark matrices, repeated measurements,
  statistical comparisons, and performance-regression checks.
  [Documentation](https://ryancswallace.github.io/benchmatrix/) ·
  [Technical deep dive](https://ryancswallace.dev/posts/benchmatrix-performance-benchmarking-as-an-experiment/)

- **[Python Project Foundry](https://github.com/ryancswallace/python-project-foundry)**
  — An opinionated generator for production-ready Python package repositories
  with testing, documentation, packaging, containers, security checks, CI, and
  release automation.
  [Documentation](https://ryancswallace.github.io/python-project-foundry/) ·
  [Case study](https://ryancswallace.dev/posts/python-project-foundry-a-production-ready-repository-in-one-command/)
